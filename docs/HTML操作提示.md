# HTML教學簡報操作

- 在專案根目錄開啟 `index.html`，保持`assets`資料夾與它在同一層。
- 共有16頁，左側的01～16可跳頁，右下角按鈕與鍵盤左右鍵可換頁。
- 第14頁有日圓預算計算器；預設數字是教學假設值，不是官方報價。
- 第15頁有3題測驗，可以作答並顯示答對題數。
- `Ctrl + P`可嘗試列印為多頁教材（依瀏覽器設定）。
- 公開部署：請上傳整個專案內容；`index.html`必須位於GitHub repository根目錄。
- 如果只想開一個HTML檔案，請使用ZIP中`docs/HTML教學簡報_單檔版.html`，不用同時複製CSS及JS。
