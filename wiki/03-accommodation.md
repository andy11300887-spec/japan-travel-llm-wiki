# 第三章：日本住宿選擇

## 一、學習目標
分辨日本常見的住宿型態；理解訂房時應比較的價格、地點與設施，並能為關西5天4夜選擇適合的住宿區域。

## 二、基本觀念
「最便宜」不一定「最划算」。房價之外，還要看與車站距離、行李空間、入住規則、退訂條件、隱私及前往每日景點的交通負擔。[S03]

## 三、詳細內容

### 3.1 西式飯店與商務飯店
一般西式飯店的設施因旅館而異；商務飯店多強調交通便利，房間常較緊湊。帶大型行李或多人同行時，要特別檢查實際房型、床數及面積。[S03]

### 3.2 日式旅館（Ryokan）
日式旅館可能提供榻榻米、和式寢具、浴衣及餐食體驗，但不是每間都相同；也有採洋式床型的房間。喜歡日本文化的旅客可納入一晚體驗。[S03]

### 3.3 青年旅舍與膠囊旅館
青年旅舍常提供多人房或共用設施；膠囊旅館的空間較小，衛浴可能共用。較適合不在意共享空間、行李較少的旅客；訂房前要看使用限制。[S03]

### 3.4 民宿及其他類型
民宿、民泊及寺院宿坊各有風格與入住規定，必須逐間閱讀房源內容。不要只看照片推斷是否有私人浴室或服務人員。[S03]

### 3.5 住宿選址的五個條件
| 檢查重點 | 問自己什麼問題？ |
|---|---|
| 交通 | 步行到車站要多久？是否常需轉乘？ |
| 位置 | 到大阪／京都／奈良當日景點順路嗎？ |
| 房價 | 是每間還是每人？含稅嗎？ |
| 設備 | 是否有大行李空間、私人衛浴與Wi-Fi？ |
| 規則 | 何時可入住、取消費用、是否限制晚歸？ |

## 四、實際例子
關西5天4夜若以大阪為住宿基地，可以減少換房次數；但京都與奈良一日遊需另外計入往返車程。若改住京都，文化景點更集中，卻可能增加其他城市移動。請依最終行程與實際房價比較，不直接宣稱其中一個絕對最好。

## 五、重點整理
**選住宿先看交通與房型，再算整趟旅費。** 訂房頁面上未寫明的服務不要自行假設。
